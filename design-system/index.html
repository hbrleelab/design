03

Plain Document

내부 기술 문서. 실험 보고, 공정 조건서, 회의록, 매뉴얼. 서신이 아니므로 엠블럼 대신 HBRLRG 워드마크를 씁니다.

HEADER ANATOMY
워드마크 좌측, 높이 17px 기준
연락 정보 우측 8.5pt, 웹 · 이메일 순
구분선 헤더 아래 12px
푸터 7.5pt 대문자, 페이지마다 반복
