HBRLRG 로고 패키지 (2026-09-03)

색상 — HBRLRG 디자인 시스템
  Navy  #14243F  RGB 20, 36, 63    CMYK 100 82 38 52
  Teal  #0EA79A  RGB 14, 167, 154  CMYK 94 0 48 4
  무채색 버전 #000000 (필요 시 아무 단색으로 치환 가능)

  CMYK 값 주의 — 2026-10-18 정정. 이전 값(Navy 68 43 0 75, Teal 92 0 8 35)은
  산술 변환이라 실제 인쇄에서 색이 어긋납니다. 특히 Teal 은 #0E7A9F 에 가까운
  파랑으로 나옵니다. 산술식은 완전한 잉크를 전제하는데 실제 공정 사이안은
  #00ADEF 로 이미 파랑 쪽이라, 청록을 내려면 노랑이 훨씬 많이 필요합니다.
  위 값은 공정 잉크 모델에서 브랜드 색으로 되돌아오는 것을 확인한 값입니다.

  다만 특정 프로파일(US Web Coated, Japan Color 등)에 맞춘 값은 아닙니다.
  인쇄소에 맡길 때는 위 CMYK 가 아니라 #14243F · #0EA79A 를 주고 그쪽
  프로파일로 변환하게 하는 편이 가장 정확합니다.

서체
  Archivo Regular(400), 자간 0.04em. 모든 글자는 아웃라인(패스)으로 변환되어
  서체 설치 없이 동일하게 렌더링됩니다.

파일
  print/*.pdf                                  인쇄용 벡터 (명함 등). RGB 와 CMYK 두 벌
  hbrlrg-horizontal-color / -mono / -reverse   가로형 (배경 투명). reverse는 어두운 배경용
  hbrlrg-horizontal-reverse-on-navy            Navy 배경 포함 (슬라이드·미리보기용)
  hbrlrg-vertical-color / -mono                세로형 (배경 투명)
  hbrlrg-symbol-color / -mono / -reverse       심볼 단독 (배경 투명)
  hbrlrg-icon (1024) / -512 / hbrlrg-favicon-64   프로필·앱 아이콘·파비콘

규격
  심볼 높이 = 대문자 높이 x 1.3, 심볼-글자 간격 = 심볼 높이 x 0.25
  엮이는 지점의 틈새는 투명하게 뚫려 있어 어떤 배경 위에서도 매듭 구조가 유지됩니다.
  최소 사용 크기(권장): 가로형 너비 120 px / 25 mm, 심볼 단독 24 px / 6 mm
