Document Design System

레터헤드 문서와 기본 문서 두 템플릿의 규격서. 공통 기반(컬러·서체·간격)과 템플릿별 조판 규칙을 정리했습니다.The specification for the letterhead and plain-document templates — the shared foundations (colour, type, spacing) and the typesetting rules particular to each.

Logo

심볼과 워드마크가 결합된 가로형이 기본입니다. 글자는 모두 아웃라인으로 변환되어 서체 설치 없이 동일하게 렌더링됩니다.The horizontal lockup — symbol plus wordmark — is the default. All lettering is converted to outlines, so it renders identically without the font installed.

The gaps where the strands cross are cut through to transparency, so the knot holds on any ground.

Rule (구분선)Rule

두 템플릿의 공통 시각 장치. 폭 전체를 지나는 1.2px 네이비 선 위에, 좌측 정렬된 46 × 3px 청록 캡을 얹습니다. 캡은 문서당 한 번만 등장합니다.The device both templates share. A 1.2 px navy line spans the full measure, with a left-aligned 46 × 3px teal cap laid over it. The cap appears once per document.

Plain Document

내부 기술 문서. 실험 보고, 공정 조건서, 회의록, 매뉴얼. 서신이 아니므로 엠블럼 대신 HBRLRG 워드마크를 씁니다.Internal technical documents — experimental reports, process condition sheets, minutes, manuals. Not correspondence, so it carries the HBRLRG wordmark instead of the emblem.

Table

수직 괘선 없음. 헤더는 Surface 배경 + 대문자 라벨, 행은 하단 괘선만. 셀 패딩 5 × 8pt.No vertical rules. The header takes a Surface fill and uppercase labels; rows carry a bottom rule only. Cell padding 5 × 8pt.
