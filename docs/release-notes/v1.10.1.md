## v1.10.1 — 카드 안 서식과 수동 쪽나눔 수정

문서팀이 하와이 가이드(5열 이상 표 21개)로 시험 빌드하며 찾아 준 결함 두 건을
고쳤습니다. 둘 다 재현해 확인했습니다.

Two defects found by the documentation team while building the Hawaii guide
(21 tables of five columns or more). Both reproduced, then fixed.

### ① 카드로 바꿀 때 칸 안의 인라인 HTML 이 사라지던 문제

표를 카드로 바꾸면서 칸의 글자만 가져오고 태그를 버렸습니다. 그래서
`<b>이름</b><br><small>위치</small>` 가 `이름위치` 로 붙었습니다. 보고된
그대로입니다.

The card conversion took each cell's text and dropped its markup, so
`<b>name</b><br><small>place</small>` came out as `nameplace`.

이제 `<br>`, `<b>`, `<strong>`, `<em>`, `<i>`, `<small>`, `<sub>`, `<sup>`,
`<code>`, `<a>`, `<span>`, `<u>`, `<s>`, `<mark>`, `<abbr>` 가 카드 제목과
값 양쪽에서 그대로 유지됩니다. 인라인이 아닌 태그는 태그만 벗고 글자는
남으므로 칸 내용이 사라지는 일은 없고, `<script>`·`<style>` 은 버립니다.

The inline tags above are now kept in both the card title and its values.
Anything else loses its tag but keeps its text, so a cell can never lose its
content; `<script>` and `<style>` are dropped outright.

카드 안에서 `<small>` 은 0.85em 의 흐린 글씨로, `<b>`/`<strong>` 은 남색
굵은 글씨로 보입니다.

### ② 수동 쪽나눔 `<div class="pb"></div>` 이 무시되던 문제

스타일시트에 해당 규칙이 아예 없었습니다. `break-before: page` 를 넣었고,
오래된 인쇄 경로를 위해 `page-break-before: always` 도 함께 둡니다.

The stylesheet simply had no rule for it. It now carries `break-before: page`,
with the legacy `page-break-before` alongside for older print paths.

```markdown
앞 문단.

<div class="pb"></div>

새 쪽에서 시작할 절.
```

자동 규칙은 카드와 표가 쪼개지지 않게 해 주지만, 어느 절이 새 쪽에서
시작해야 하는지는 글쓴이만 압니다.

### 검증 · Verification

| 확인 | 결과 |

샘플 원고(`mobile/sample/hawaii-guide.md`)도 두 기능을 실제로 쓰도록 고쳤으니,
동작을 보시려면 그 PDF 를 열어 보시면 됩니다.

The sample now exercises both features, so the shipped PDF demonstrates them.

### 그대로 둔 것

본문 11.5pt 는 가독성에 좋다고 하셨으므로 건드리지 않았습니다. 로고 비율도
변경 없습니다 — 보고해 주신 3.357 대 3.390 은 약 0.97% 차이로, 문서에 적어 둔
허용치 1% 안입니다. 이쪽에서 렌더 박스를 직접 재면 3.3895 대 3.3898(0.011%)
이므로, 차이는 PDF 를 이미지로 바꿔 재는 과정의 반올림으로 보입니다.

Body text stays at 11.5pt, and the logo is unchanged: the 3.357 against 3.390
you measured is 0.97% apart, inside the 1% tolerance the documentation states.
Measured here from the rendered box it is 3.3895 against 3.3898 — 0.011% — so
the difference looks like rounding in rasterising the PDF before measuring.

**실제 휴대폰과 카톡 뷰어에서는 여전히 열어 보지 못했습니다.** 이 환경에
휴대폰이 없습니다. 배포 전 확인 단계는 그대로 남겨 주시기 바랍니다.
