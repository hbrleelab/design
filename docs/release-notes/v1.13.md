## v1.13 — 학회 포스터 템플릿 · Conference poster templates

([`references/posters/`](https://github.com/hbrleelab/design/tree/main/references/posters))

Rebuilt from the four layout references: three styles in two sizes, six files.

### 참고 자료와 다르게 한 것 · Where it departs from the references

- **제목은 왼쪽 맞춤.** 참고 4장은 모두 가운데였지만, 연구실 슬라이드 · 문서
  제목은 모두 왼쪽이고 규격이 로크업 가운데 정렬을 금합니다. 엠블럼 오른쪽에
  레터헤드와 같은 구조로 두었습니다.
- **섹션 제목은 한 가지.** 02 의 남색 띠, 03 의 회색 테두리 상자 대신 청록 번호 +
  남색 제목 + 옅은 선. 청록 캡 구분선은 규격대로 한 장에 한 번만.
- **04 의 섹션별 1–3단 구성은 따르지 않음.** `band` 는 04 의 띠만 가져오고 2단
  격자를 유지했습니다.
- 750 × 1250 (04) 와 축소 출력본(01) 은 판형 근거로 쓰지 않았습니다.

### v1.12 에서 바뀐 것 · Changes from v1.12

- `hbrlrg-poster-a0-portrait.pptx` (3단 초안) 는 없어지고 위 6개로 바뀌었습니다.
- **v1.12 는 섹션마다 청록 캡 구분선을 썼는데, 규격(§4 "문서당 한 번")에
  어긋났습니다.** 이번 판은 standard 머리 아래 한 번만 씁니다.
- 학생용 README 를 영문으로 새로 썼습니다 (판형 고르기, 글자 하한, 그림 넣는 법,
  인쇄).
