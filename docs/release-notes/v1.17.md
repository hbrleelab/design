## v1.17 — 슬라이드 컴포넌트 · Slide components

슬라이드 안에 넣는 내용 유형별 디자인(컴포넌트) 14종을 더하고, 표지·맺음의 소속 간격을 고쳤습니다.
v1.15·v1.16은 내부 시안 번호라 릴리스 없이 v1.17로 바로 냅니다.

Fourteen content components for what goes *inside* a slide, and a fix to the
affiliation spacing on the cover and closing. (v1.15 and v1.16 were internal
drafts; this is the first release of the components.)

### 무엇이 새로 생겼나 · What's new
- `components/hbrlrg-slide-components.pptx` — 컴포넌트마다 변형 2~6개, 장 하나씩 복사해 쓰는 덱(표지·맺음 light·dark 포함, 53장) · one slide per variant
- `components/slide-components.md` — 컴포넌트별 컨셉·디자인 요소·변형과 쓰는 상황·하지 말 것·학생용 한 줄 · rules per component
- `components/tokens-slide-components.json` — 회색 단계·남색 틴트·청록 바탕·화살표·관계 노드 토큰 · tokens
- `components/preview/` — 장별 미리보기와 `00_overview.png`

### 원칙 · Principles
- 결론 문장 제목, 회색 맥락 + 청록 강조 하나, 범례 대신 직접 라벨, 출판 데이터엔 출처 한 줄 · sentence titles, grey + one teal, direct labels, a source line
- 큰 숫자 타일은 기본에서 뺐습니다 — 수치는 제목과 데이터 위에(C1) · no big-number tiles by default
- 인과관계(C13)는 일자·원형·삼각·수렴·발산·피드백 루프 6형, 관계 노드만 둥근 모서리 허용 · six causal layouts; rounded nodes only in C13/C14

### 고친 것 · Fixed
- 표지·맺음 소속: Chem. Mater. 로고 파일의 투명 여백 때문에 로고와 글자 사이가 UNIST(12 pt)보다 두 배(23 pt) 벌어지던 문제. 이제 두 블록 모두 보이는 로고 가장자리에서 12 pt, 밝은 판·어두운 판 같음(`tools/build_office.py` `lockup()`, `slides/slides-en-*.html`). · CM logo text gap now matches UNIST on both grounds.
