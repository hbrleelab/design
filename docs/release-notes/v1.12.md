### ⚠ 초안입니다 · This is a draft

학생 포스터에서 뽑은 레이아웃 참고 자료가 아직 들어오지 않아서, 이 판은
**디자인 시스템만을 기준으로** 만들었습니다. 자료가
[`references/posters/`](https://github.com/hbrleelab/design/tree/main/references/posters)
에 들어오면 격자를 고치고, 자료에 나오는 판형(가로형 · A1 등)으로 변형판을
더합니다. 참고 자료를 넣는 양식은 그 폴더의 README 에 있습니다.

No layout references have arrived yet, so this version follows the design
system alone. The grid will be revised, and variants added, from the references
in `references/posters/`.

### 구성 · What is on it

| | |
| --- | --- |
| 머리 (네이비) | HBRLRG 로고 · 학회명과 포스터 번호 · 제목 100 pt · 저자 40 pt · UNIST 엠블럼과 소속 |
| 본문 3단 | 01 Introduction · 02 Methods · 03 Results · 04 Discussion · 05 Conclusion · References |
| 꼬리 (회색) | 연락처 · 사사 · 연구실 홈페이지 QR |
| 그림 자리 | 4개. 폭은 모두 한 단(243 mm), 안에 자리 크기(mm)가 적혀 있음 |

- **글자 크기는 거리에서 나왔습니다.** 제목은 통로 건너편(약 5 m), 본문은 바로
  앞(약 1.5 m)에서 읽히는 크기입니다. 본문 30 pt 가 하한이고, 어떤 글자도 20 pt
  아래로 내려가지 않습니다.
- **세 단의 끝선이 같습니다.** 단마다 그림 하나가 글이 남긴 높이를 차지하게 해서
  맞췄습니다.
- 색 · 서체 · 로고는 v1.11 규격 그대로입니다. 엠블럼은 슬라이드 표지와 같은 비율
  (소속 글자 크기의 3.5배)로 소속 문구 옆에만 놓았습니다.
- Archivo 4종 · Pretendard 2종을 파일 안에 넣었습니다(슬라이드와 같음).

### 검증 · Verification

| 확인 | 결과 |
| --- | --- |
| ISO/IEC 29500 스키마 | 통과 — 릴리스 워크플로의 검사 대상에 포스터를 추가 |
| PDF 변환 (LibreOffice) | A0 841 × 1189 mm, 1쪽, Archivo 임베드 |
| 글 넘침 | 없음 — 글 상자마다 Archivo 실제 글자 폭으로 줄 수를 재서 높이를 정함 |
| 단 끝선 | 세 단 모두 1079.0 mm |
| 글머리 기호 | 첫 줄 x-height 가운데에 맞춤 (렌더에서 확인) |

**파워포인트에서 직접 열어 보지는 못했습니다.** 이 환경에 파워포인트가 없어
LibreOffice 로 렌더를 확인했습니다. 첫 사용자는 열었을 때 이상한 점이 있으면
알려 주세요.

PowerPoint itself was not available here; rendering was checked in LibreOffice.

### 그 밖에

- `tools/build_poster.py` — 포스터 생성기. 판형은 `FORMATS` 의 항목 하나이므로,
  변형판은 항목을 더하는 일입니다. 한 단에 글이 너무 많아 그림 자리가 100 mm
  아래로 줄면 멈추고 알려 줍니다.
