## v1.14 — 밝은 슬라이드 판 · Light slide deck

슬라이드 템플릿에 밝은 판을 더했습니다. 기존 판은 그대로 두고, 파일 이름으로
둘을 구분합니다.

A light version of the slide deck. The existing deck is unchanged; the two are
told apart by file name.

| | 어두운 판 (기존) | 밝은 판 (새로) |
| --- | --- | --- |
| PowerPoint | `hbrlrg-slides-dark.pptx` | `hbrlrg-slides-light.pptx` |
| 브라우저 (미리보기 · 발표) | `slides/slides-en-dark.html` | `slides/slides-en-light.html` |

**고르는 법** → [README «Dark or light»](https://github.com/hbrleelab/design#dark-or-light--어두운-판과-밝은-판-고르기)
— 어두운 강당 · 기조 강연이면 어두운 판, 밝은 세미나실 · 약한 프로젝터 · 인쇄나
PDF 로 읽힐 발표면 밝은 판. 한 발표 안에서 섞지 않습니다.

### 무엇이 바뀌나 · What changes

기존 판도 12장 중 7장(목차 · 본문 · 그림 3종 · 표 · 수치)은 이미 흰색이나 옅은
회색 바탕이었습니다. 밝은 판은 나머지 **어두운 다섯 장**만 밝은 바탕으로 옮기고,
레이아웃 · 좌표 · 글자 크기는 모두 같습니다.

| 슬라이드 | 어두운 판 | 밝은 판 |
| --- | --- | --- |
| 표지 · 맺음 | 남색, 반전 로고, `unist-emblem-onnavy` | 흰색, 일반 로고, `unist-emblem`(밝은 배경용), 구분선 `#E4E7EC` |
| 섹션 구분 | 남색 | 옅은 회색 `#F6F7F9`, 남색 제목 — 흰 본문 사이에서 쉼표로 읽히도록 |
| 전면 이미지 | 남색 그러데이션 위 흰 설명 | 흰 설명판 위 남색 설명 — 사진 위에 남색 글자를 바로 얹으면 읽히지 않는 경우가 많음 |
| 선언 | 청록 바탕, 흰 글자 | 흰 바탕, 남색 글자, 청록 따옴표 |

디자인 규칙 — 밝은 바탕에는 일반 로고 파일(색을 바꾸지 않고 파일을 바꿈), 청록
캡은 모든 슬라이드에서 같은 자리, 청록을 작은 본문 글자색으로 쓰지 않음. CM 로고는
자체 흰 박스가 있어 두 판에 같은 파일을 씁니다. 규격서에 §7-2 «밝은 판» 을
더했습니다.

### ⚠ 파일 이름이 바뀌었습니다 · Renamed files

- `hbrlrg-slides.pptx` → **`hbrlrg-slides-dark.pptx`** (내용은 v1.13 과 바이트 단위로 같음)
- `slides/slides-en.html` → **`slides/slides-en-dark.html`** (내용 그대로)

예전 이름으로 링크해 둔 곳이 있으면 고쳐 주세요.

### 검증 · Verification

| 확인 | 결과 |
| --- | --- |
| 어두운 판이 그대로인지 | `hbrlrg-slides-dark.pptx` 의 모든 파트가 v1.13 `hbrlrg-slides.pptx` 와 동일, HTML 도 동일 |
| ISO/IEC 29500 스키마 | 두 판 모두 통과 |
| 렌더 | PPTX 는 LibreOffice, HTML 은 Chromium 인쇄로 12장 모두 확인 |

**파워포인트에서 직접 열어 보지는 못했습니다.**

### 함께 고친 것 · 알려 둘 것

- **밝은 판에서만 고친 것: 꼬리말 섹션 이름 중복.** 기존 HTML 본문 슬라이드의 꼬리말에
  섹션 이름이 두 번 나옵니다(로고 | ALD Fundamentals | ALD Fundamentals). 규격(§7)은
  한 번입니다. 밝은 판 HTML 은 한 번으로 고쳤고, 어두운 판은 "그대로 두라" 는
  지시에 따라 손대지 않았습니다. PPTX 는 두 판 모두 원래 한 번입니다.
- 밝은 판 PPTX 는 도형의 테마 그림자 참조를 지웠습니다. 파워포인트는 원래 그림자를
  그리지 않지만 LibreOffice · Keynote 는 흰 바탕에서 막대 아래 회색 번짐을 그립니다.
  어두운 판은 같은 이유로 손대지 않았습니다(남색 위에서는 보이지 않음).
