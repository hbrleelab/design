### ⚠ 규격서의 CMYK 값이 틀렸습니다 · The documented CMYK was wrong

작업 중 발견한 문제입니다. 로고 README 에 적혀 있던 CMYK 값은 교과서 산술
변환이라 **실제 인쇄에서 색이 어긋납니다.**

Found while doing this. The CMYK in the logo README was the textbook arithmetic
conversion, and it does not print as the brand colour.

| | 이전 값 | 인쇄 결과 | 정정 값 | 인쇄 결과 |
| --- | --- | --- | --- | --- |
| Navy `#14243F` | 68 / 43 / 0 / 75 | `#202942` | **100 / 82 / 38 / 52** | `#14243F` |
| Teal `#0EA79A` | 92 / 0 / 8 / 35 | `#0E7A9F` ← 파랑 | **94 / 0 / 48 / 4** | `#0EA79A` |

산술식은 완전한 잉크를 전제합니다. 실제 공정 사이안은 `#00ADEF` 로 이미 파랑
쪽이라, 청록을 내려면 노랑이 훨씬 많이(8 → 48) 들어가고 검정은 훨씬 적게
(35 → 4) 들어갑니다. **이전 값으로 인쇄한 것이 있다면 청록이 파랑으로 나왔을
것입니다.**

The formula assumes perfect inks. Real process cyan sits near `#00ADEF`, well
towards blue, so a green-teal needs far more yellow (8 → 48) and far less black
(35 → 4). **Anything printed from the old numbers will have come out blue.**

정정 값은 공정 잉크 모델에서 브랜드 hex 로 되돌아오는 것을 확인했습니다. 다만
특정 프로파일(US Web Coated, Japan Color 등)에 맞춘 값은 아니므로, **인쇄소에는
CMYK 가 아니라 `#14243F` · `#0EA79A` 를 주고 그쪽 프로파일로 변환하게 하는
편이 가장 정확합니다.**

### 검증 · Verification

| 확인 | 결과 |
| --- | --- |
| SVG 원본 | PNG 와 대조 — 뚜렷이 다른 픽셀 0.047% (안티앨리어싱 수준) |
| 벡터 여부 | 8개 파일 모두 래스터 XObject 없음 |
| 글자 아웃라인 | 폰트 참조 없음 — 서체 없는 PC 에서도 동일 |
| 페이지 크기 | 가로형 40.000 mm, 심볼 12.000 mm, 아트워크에 딱 맞게 재단 |
| 비율 | 3.3915 — SVG 원본과 동일 |
| 색 (RGB 판) | `#14243F` · `#0EA79A` 정확히 재현 |
| 색 (CMYK 판) | `#13243E` · `#0FA89B` — 1/255 반올림 오차 |
| 반전본 | 네이비 위에 합성 확인 — 흰 글자, 청록 심볼, 매듭 틈 유지 |

**실제 인쇄기를 거치지는 않았습니다.** 본 인쇄 전 교정쇄를 요청하시고, 특히
청록을 확인하세요.

**Nothing here has been through a real press.** Ask for a proof before a run.
