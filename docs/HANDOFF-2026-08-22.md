## 3. 스킬 `hbrlrg-design`

`.claude/skills/hbrlrg-design/` — 자기완결형입니다. 다른 프로젝트에서 쓰려면
`~/.claude/skills/` 로 복사하면 됩니다.

```
SKILL.md              토큰, 핵심 규칙 2개, 소속 표기, 워드마크 SVG
references/slides.md      1920×1080 그리드, 헤더/본문/푸터 좌표, 표지 레이아웃
references/documents.md   A4 규칙, 인쇄 동작
references/pptx.md        PPTX 재스타일링 — 토큰 맵, 폰트 임베드, 함정
scripts/otf2ttf.py        OTF→TTF (PowerPoint는 TrueType만 임베드)
scripts/embed_fonts.py    PPTX 폰트 임베드 + 패키지 배선
scripts/qa_fit.py         렌더러 없이 텍스트 넘침·이탈·겹침 검사
assets/logos/             로고 3종
assets/templates/         템플릿 원본 + 뷰어/인쇄 엔진 + CSS
```

스크립트 의존성: `pip install python-pptx fonttools cu2qu Pillow`

**디자인 토큰** (전체는 SKILL.md)

| 토큰 | 값 | 용도 |
|---|---|---|
| Navy | `#14243F` | 제목·이름·구분선·로고 본체 |

## 4. 환경 제약 — 클라우드 세션에서 막힌 것들

이 세션이 Anthropic 클라우드에서 돌아서 겪은 제약입니다. Documentation 세션은
로컬 브리지라 **대부분 해당 없을 것**이고, 오히려 여기서 못 한 일을 할 수 있습니다.

| 막힌 것 | 증상 | 로컬에서는 |
|---|---|---|
| **태그 푸시** | `git push origin v1.0` → 403. 프록시가 작업 브랜치 외 푸시를 차단 | 가능 — v1.0 릴리스는 이쪽에서 하면 됩니다 |
| 레포 설정 변경 | `PATCH /repos/...` → "Repository settings writes are not permitted" | 가능 |
| git ref 생성 | `POST /git/refs` → "Write access to this GitHub API path is not permitted" | 가능 |
| Pages 상태 API | `GET /repos/.../pages` → 차단 | 가능 |
| **LibreOffice** | `soffice --convert-to pdf` 가 **1장짜리 빈 pptx조차** 실패. 렌더링 검증 불가 | 정상이라면 시각 검증 가능 |
| Dropbox 다운로드 | `*.dl.dropboxusercontent.com` egress 차단 | 가능 |
| 외부 도메인 | `fonts.google.com`, `hbrleelab.github.io` 차단. `raw.githubusercontent.com` 은 통과 | 가능 |
| 첨부 용량 | 약 30MB 초과 시 업로드 불가 | — |

**GitHub 앱** — 처음에 푸시가 403이었던 원인은 *Claude Design Import* 앱만 설치돼
있었기 때문입니다. 그 앱은 읽기 전용 고정이라 권한 조정이 불가능하고, 별도로
`https://github.com/apps/claude` (Claude Code용)를 설치해야 쓰기가 열립니다. 지금은
설치 완료 상태입니다.

## 6. 알아둘 함정 — 다시 부딪히지 않게

### python-pptx 가 테두리를 그린다

`shape.line.color` 를 **읽기만 해도** `<a:ln>` 요소가 생성됩니다
(`LineFormat.fill` → `_get_or_add_ln()`). 결과가 `<a:ln><a:solidFill/></a:ln>` —
색 없는 solid fill이고, PowerPoint는 이걸 검은 외곽선으로 그립니다. "이 도형에 선
색이 있나?" 확인하는 것만으로 덱 전체 텍스트 상자에 테두리가 박힙니다.

XML에서 직접 읽으세요. 우회 코드와 검증 스니펫은
`.claude/skills/hbrlrg-design/references/pptx.md` 에 있습니다.

### PowerPoint는 TrueType만 임베드한다

Pretendard는 CFF 아웃라인 `.otf` 라 그대로는 임베드가 안 됩니다.
`scripts/otf2ttf.py` 로 변환하세요 (14,716 글리프, 1~2분).

### 렌더러 없이 맞춤 검사

`scripts/qa_fit.py` 가 실제 Archivo 글자폭으로 줄바꿈을 계산해 넘침·이탈·겹침을
잡습니다. **원본에도 같이 돌리세요** — 내가 만든 결함과 원래 있던 결함이 구분됩니다.
AMAT 덱에서 이걸로 원본의 그림 이탈·제목 넘침을 찾아냈습니다.

### Archivo는 Helvetica/Arial보다 넓다

폰트만 갈아끼우면 기존에 한 줄이던 제목이 두 줄로 꺾입니다. 제목이 안 맞으면
**덱 전체 제목 크기를 내리세요** — 몇 장만 줄이면 실수처럼 보입니다.

## 7. 이 컨테이너와 함께 사라지는 것

세션 컨테이너는 회수되면 스크래치패드가 지워집니다. 레포에 없는 것들:

- AMAT 덱 빌드 스크립트 (`build.py`, `embed_fonts.py`, `qa_fit.py`, `otf2ttf.py`)
  → 별도 zip으로 사용자에게 전달함. 범용 3종은 스킬 안에 영구 보존됨
- 변환된 폰트 파일 (Archivo TTF 4종, Pretendard TTF 2종)
  → 출처에서 다시 받으면 됩니다. Archivo: `github.com/Omnibus-Type/Archivo/fonts/ttf`,
    Pretendard: `github.com/orioncactus/pretendard/releases` (받은 뒤 otf2ttf.py)
- Claude Design hand-off 원본 zip들 → 사용자 Dropbox 루트에 있음

레포와 스킬에 들어간 것은 전부 영구 보존됩니다.

## 8. 판단이 필요했던 결정들

**`.dc.html` 을 레포에 넣지 않음.** Claude Design의 저작 원본(`Slide Template.dc.html`
등)과 레포의 배포용 HTML을 텍스트 비교한 결과 **내용이 100% 동일**했습니다(`<title>`
유무만 차이). 그런데 `.dc.html` 은 `support.js`(dc-runtime)가 unpkg.com에서 React +
Babel 약 3MB를 받아 브라우저에서 JSX를 실시간 컴파일하는 구조라, 네트워크가 없으면
**빈 화면**이 됩니다. 레포 버전은 폰트만 CDN이라 최악의 경우 시스템 폰트로 대체될
뿐 내용은 나옵니다. 학회장·기내처럼 망이 불안한 곳에서 발표하는 용도이므로 레포
버전을 유지하기로 사용자와 합의했습니다.

**플레이스홀더 빨강 유지.** 작업 중인 덱의 `[INSERT DATA]` 표시는 브랜드 색으로
바꾸지 않았습니다. 티일로 칠하면 "채워야 할 자리"가 완성된 디자인처럼 보여서 하나
빠뜨린 채 발표할 위험이 있습니다. 강조용으로 쓰인 빨강만 티일로 바꿨습니다.

**국문 슬라이드 삭제.** 사용자 방침이 영문판 단일 유지. 구버전을 남기면 학생이
어느 게 최신인지 알 수 없어 파일을 지우고 README·DEPLOY 참조도 정리했습니다.
