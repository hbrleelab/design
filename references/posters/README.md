# Poster layout references · 포스터 레이아웃 참고 자료

비서실이 학생 포스터에서 **레이아웃만** 뽑아 넣는 곳입니다. 여기 자료를 분석해
[`posters/`](../../posters/) 템플릿의 격자를 고치고 변형판(가로형 · A1 등)을 만듭니다.

Layout-only references extracted from students' posters. They are analysed to
revise the grid of the [`posters/`](../../posters/) template and to add variants.

## 넣지 않을 것 · Keep out

- 포스터 원본 파일 (PPTX · PDF · AI). 미발표 데이터가 들어 있습니다.
- 학생 이름, 그림, 본문 문장. 와이어프레임은 상자와 자리 표시만 남깁니다.
- 다른 기관 로고가 보이는 이미지 — 자리만 상자로 표시하세요.

## 한 포스터에 폴더 하나 · One folder per poster

```
references/posters/
  01-mrs-fall-2025/
    wireframe.png      내용을 가린 와이어프레임 (긴 변 2000 px 정도면 충분)
    layout.md          아래 양식
  02-kcs-2026/
    ...
```

폴더 이름은 `번호-학회-연도` 로 해 주세요. 학생 이름은 넣지 않습니다.

## layout.md 양식 · Template

치수는 mm, 글자는 pt 로 적어 주세요. 모르는 칸은 비워 두면 됩니다 — 와이어프레임에서
잴 수 있습니다.

```markdown
# 01 — MRS Fall 2025

## 판형
- 크기: 841 × 1189 mm (A0)        ← 학회가 정한 크기 그대로. 예: 48 × 36 inch
- 방향: 세로 / 가로
- 학회 규정: (있으면 링크나 문구)

## 단 구성
- 단 수: 3
- 단 폭: 같음 / 다름 (다르면 비율, 예: 1 : 2 : 1)
- 여백 · 단 간격: 약 30 mm / 20 mm

## 머리 · 꼬리
- 머리 높이: 약 200 mm. 들어 있는 것: 제목 · 저자 · 소속 · 로고(위치)
- 꼬리: 있음 / 없음. 들어 있는 것: 연락처 · 사사 · QR

## 섹션 배치
단마다 위에서 아래로:
- 1단: Introduction → Methods (그림 1)
- 2단: Results (그림 2, 3)
- 3단: Results 계속 (그림 4) → Conclusion → References

## 글자 크기 위계
| 역할 | 크기 (pt) |
| --- | --- |
| 제목 | |
| 저자 | |
| 섹션 제목 | |
| 본문 | |
| 그림 설명 | |
| 참고문헌 | |

## 그림
- 개수: 4
- 비율: 그림 1 4:3, 그림 2 16:9 (가로로 두 단 걸침), ...
- 그림이 차지하는 면적: 본문 영역의 약 절반

## 눈에 띄는 점
- 예: 결론을 맨 위 가운데 상자에 따로 둠, 2단에 걸친 큰 그림, 요약 상자 등
```

## 분석 기록 · Analysis

자료가 들어오면 판형별로 묶어 이 아래에 정리합니다 — 몇 장이 어떤 판형이었는지,
단 구성과 글자 크기의 공통점, 템플릿에 반영한 것과 반영하지 않은 것과 그 이유.

### 2026-10-19 첫 묶음 — 4장 (연구실 학생 1명 제공, 슬랙 #slide-materials)

| 폴더 | 판형 | 단 | 머리 | 꼬리 | 제목 / 섹션 / 본문 pt |
| --- | --- | --- | --- | --- | --- |
| [01](01-kchips-kickoff-2026/layout.md) 과제 착수 | 축소 PDF(1 : 1.56) 세로 | 2단 → 1단 3열 | 14 % | 명단 띠 | A0 환산 65 / 56 / 28 |
| [02](02-kchips-workshop-2026/layout.md) 과제 워크숍 | A0 841 × 1189 세로 | 2단 같은 폭 | 12 % | 명단 2칸 | 64 / 40 / 14–18 |
| [03](03-kcs-2026/layout.md) 학회(KCS) | 900 × 1200 세로 | 2단 같은 폭 | 14 % | 로고 띠 | 80 / 52 / 24–28 |
| [04](04-unist-semi-lab-showcase-2026/layout.md) 연구실 쇼케이스 | 750 × 1250 세로 | 섹션별 1–3단 | 16 % | 행사 띠 | 130 / 60 / 44 |

**공통점**
- 넷 모두 **세로형**. 학회·과제용 셋(01–03)은 **2단 같은 폭**, 머리는 판 높이의 12–16 %.
- 머리 구성은 같음: 제목(가운데) + 저자·소속 + 양쪽 로고(학교 · 과제/학회).
- 그림 비율은 1.2–1.7(가로)이 가장 많고, 공정 단계를 보여 주는 **가로 띠(3 : 1 이상)** 가 단 폭을 가로지름. 세로 그림은 대개 사진·구조.

**다른 점 · 템플릿에 반영할 것(제안)**
- 본문 글자: 02(A0)는 14–18 pt로 작고, 03은 24–28 pt로 읽기 좋음 → 템플릿 본문 **24 pt 이상**, 그림 설명 **20 pt 이상** 권장.
- 위계가 가장 정돈된 것은 03(80 / 52 / 40 / 28 / 24) — 기본값 후보.
- 03은 단 사이가 약 5 mm로 좁음 → 단 간격 20 mm 이상.
- 01·02의 「짙은 바탕 + 흰 패널」, 04의 「남색 머리·꼬리 띠」는 연구실 남색과 맞음 — 변형판(과제 보고용 · 전시용) 후보.

**와이어프레임 읽는 법** — 남색 막대 = 제목 등급, 청록 = 섹션·소제목 등급, 회색 = 본문, 옅은 회색 = 그림 설명·작은 글. X 상자 = 그림·사진·로고 자리(다른 기관 로고 포함, 모두 상자로만), 옅은 테두리 = 패널·면. 글과 그림 내용은 모두 지웠습니다.

### 템플릿 반영 결과 · What the template took (v1.13)

| 제안 | 반영 | 비고 |
| --- | --- | --- |
| 세로, 2단 같은 폭 | ✅ | 01–03 공통. 단 폭 A0 378.5 mm · KCS 408 mm |
| 머리 12–16 % | ✅ | A0 15.6 % (standard) · 14.9 % (panel · band). 생성기가 16 % 를 넘으면 멈춤 |
| 머리: 제목 + 저자·소속 + 양쪽 로고 | ✅ | 왼쪽 UNIST 엠블럼(소속 문구와 같은 머리 안), 오른쪽 학회·과제 로고 자리 |
| 위계 80 / 52 / 40 / 28 / 24 (03) | ✅ | 제목 / 섹션 / 소항목·저자 / 본문 / 그림 설명. 소속 · 참고문헌 · 꼬리 20–24 |
| 본문 ≥ 24 pt, 그림 설명 ≥ 20 pt | ✅ | 기본은 본문 28 · 설명 24. README 에 하한으로 명시, 그림 속 글자에도 적용 |

**반영하지 않은 것**

- **제목 가운데 정렬.** 참고 자료 넷 다 가운데였지만, 연구실 슬라이드 · 문서의
  제목은 모두 왼쪽 맞춤이고 규격(§7-1)은 로크업 가운데 정렬을 금합니다. 엠블럼
  오른쪽에 왼쪽 맞춤으로 두어 레터헤드 머리글과 같은 구조로 했습니다.
- **섹션 제목 띠(02 의 남색 띠, 03 의 회색 테두리 상자).** 청록 번호 + 남색 제목
  + 옅은 선으로 통일했습니다. 청록 캡 구분선은 규격대로 한 장에 한 번(standard
  머리 아래)만 씁니다.
- **750 × 1250 (04).** 행사 지정 크기 1장뿐이라 판형으로 두지 않았습니다.
- **축소 출력본(01).** 실제 인쇄 크기를 알 수 없어 판형 근거로 쓰지 않았습니다.
